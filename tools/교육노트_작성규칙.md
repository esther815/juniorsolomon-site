# 솔로몬 저널 — 기사 올리기 작업 지침 (새 채팅용)

> 원장님이 기사 캡처나 링크를 주면, 이 지침대로 정리해 **juniorsolomon.com/note.html**(솔로몬 저널)과
> 홈페이지 첫 화면의 '솔로몬 저널' 미리보기(최신 3건)에 올린다.
> 대상 독자: 유아·초등 학부모 (중학생 학부모 일부 포함).
> 원본 규칙: 소포스 입시 노트(`esther815/sophosedu-site` 의 `tools/입시노트_작성규칙.md`). 글쓰기 원칙은 같다.

---

## 0. 운영 방식 (반드시 이 순서)

1. 원장님이 기사 캡처나 링크를 준다.
2. **원문을 찾아 확인한다.** 캡처만 있으면 언론사·제목으로 원문을 검색해 url 과 게재일을 확인한다. 원문을 찾지 못하면 그 사실을 보고하고, 캡처 내용만으로 숫자·날짜를 쓰지 않는다.
3. **시안을 채팅에 보여 준다.** (아래 5장 형식) 이때는 저장소에 올리지 않는다.
4. 원장님이 「올려」라고 하면 그때 main 에 게시한다.

### 알림톡 (중요)
- 알림톡이 켜진 뒤(`ALIMTALK_MODE=live`)에는 **main 에 올리는 순간 재원생 구독 학부모께 카카오 알림톡이 나간다.** 되돌릴 수 없다.
- 그래서 「올려」 전에는 절대 main 에 올리지 않는다. 개발 브랜치에만 저장한다.
- 알림톡에는 제목 · 세 줄 요약 · 솔로몬 노트가 그대로 들어간다(1,000자 이내). 오탈자는 올리기 전에 고친다.
- 이미 올린 기사를 고쳐도 알림톡은 다시 나가지 않는다(새 id 만 발송). 중대한 오류는 원장님께 바로 보고한다.
- 준비·설정: `supabase/알림톡_준비_안내.md`

## 1. 한 번만 준비 (새 채팅을 열 때마다)

1. 저장소 **esther815/juniorsolomon-site** 에서 작업한다.
2. 이 파일을 처음부터 끝까지 읽는다.
3. 다른 채팅도 같은 저장소에 올리므로 **작업 시작 전과 올리기 직전에 `git pull --rebase`**.

## 2. 손대는 파일 — 이것만

| 파일 | 하는 일 |
|---|---|
| `data/note.json` | 기사 목록. **여기에 한 건씩 추가만 한다.** |
| `tools/update_note.py` | 실행하면 `note.html`과 `index.html` 미리보기를 다시 만든다. 검사도 해 준다. |
| `note.html`, `index.html`의 `<!--NOTE:START-->`~`<!--NOTE:END-->` | 스크립트가 만든다. **손으로 고치지 않는다.** |

그 밖의 파일(`member.html`, `assets/`, `consult.html`, `fees.html` 등 로그인·결제·상담 기능)은 절대 건드리지 않는다.

## 3. 한 건의 모양 (`data/note.json` 배열 맨 앞에 객체 하나 추가)

```json
{
  "id": "2612-03-reading-survey",
  "date": "2026-12-03",
  "cat": "독서·문해력",
  "source": "언론사 이름",
  "url": "https://원문 주소",
  "title": "제목만 읽어도 무슨 일인지 아는 한 문장",
  "deck": "배경과 핵심을 담은 두 문장. 합쳐서 90자 안팎.",
  "points": [
    "기사 속 사실 한 문장",
    "기사 속 사실 한 문장",
    "기사 속 사실 한 문장"
  ],
  "note": "학부모가 지금 할 일 한두 문장. 존댓말로 씁니다."
}
```
(위는 모양을 보여 주는 틀이다. 실제 기사가 아니다.)

### 칸별 규칙
- **id**: `YYMM-DD-영문짧은말` (기사 게재일 기준). 겹치면 끝에 `-2`.
- **date**: 기사 **게재일** `YYYY-MM-DD`. 오늘 날짜가 아니다. 요일은 자동 표시.
- **cat**: 다음 넷 중 하나만 — `교육정책` · `초등` · `독서·문해력` · `평가`
  - 교육부·교육청 정책 일반, 유보통합·늘봄 등 제도 → `교육정책`
  - 초등 교육과정·교과서·학교생활·입학 → `초등`
  - 독서·문해력·어휘·디지털 읽기 → `독서·문해력`
  - 학교 평가 방식(서·논술형, 성취평가, 학력 진단) → `평가`
  - **중학교 내신·고입·대입 기사는 여기에 올리지 않는다.** 원장님께 "소포스 입시 노트 대상입니다"라고 보고한다. (원장님 결정, 2026-11-25: 중등·고입은 소포스와 연동하고 별도로 만들지 않는다. 솔로몬 저널 페이지에는 소포스 입시 노트 바로가기가 있다.)
- **source**: 언론사 이름만. 기자 이름 쓰지 않는다.
- **url**: 원문 주소 그대로. 모바일 주소(`m.`)는 PC 주소로 바꿀 수 있으면 바꾼다. `?utm_...` 꼬리는 지운다.
- **title** (제목): 28자 안팎 한 문장. 기사 제목을 베끼지 않고 새로 쓴다. 사실을 담는다(누가·무엇이·어떻게 됐다).
  물음표·느낌표·말줄임표·자극적 표현(충격, 비상, 대혼란 등) 금지 — 스크립트가 잡아낸다.
- **deck** (한두 줄 풀이): 2문장, 합쳐서 90자 안팎.
- **points** (세 줄 요약): **정확히 3개**. 각 1문장, 70자 안팎. 기사에 있는 **사실**만, 내 말로.
  - 숫자·날짜·기관명은 기사와 똑같이. 확인 안 되면 넣지 않는다.
  - 전망·주장은 누구의 말인지 밝힌다("교육부는 ~할 계획이다", "연구진은 ~로 본다").
- **note** (솔로몬 노트): 학부모가 **지금 할 일** 한두 문장. 존댓말("~하세요", "~입니다").
  - 유아·초등 가정에서 실제로 할 수 있는 일로 쓴다(예: 가정통신문 확인, 함께 읽기, 학교 설명회 일정 확인).
  - 해석·조언은 여기에만 쓴다. 과장·불안 조성·학원 홍보 문구 금지("저희 학원에서", "지금 등록" 등 쓰지 않는다).
  - 날짜를 쓰면 반드시 공식 일정과 대조한다.

## 4. 글쓰기 원칙 (반드시 — 소포스 규칙 3장과 같다)

1. **저작권**: 기사 문장을 그대로 옮기지 않는다. 15단어 넘는 인용 금지, 한 기사에서 인용은 최대 한 번(되도록 0번). 문장 구조까지 바꿔 완전히 내 말로 쓴다.
2. **사실과 조언을 나눈다**: points = 기사 속 사실, note = 솔로몬의 조언.
3. **모르면 쓰지 않는다**: 기사에 없는 숫자·날짜·학교명을 지어내지 않는다. 검토·계획 단계면 "검토", "계획", "추진"으로 쓴다. 확정처럼 쓰지 않는다.
4. **말투**: 품위 있고 담백하게. 학부모가 처음 읽어도 아는 말로. 약어는 처음에 풀어 쓴다(예: 고교학점제 → 처음 한 번 설명).
5. **한 기사 = 한 건**이 기본. 성격이 다른 두 주제가 뚜렷하면 두 건으로 나눌 수 있다(검사에서 '참고'로 알려 줌).
6. 정치적 입장·특정 학교/학원 비방·광고성 문구를 넣지 않는다.
7. 한자어를 풀어 쓸 때는 원장님 공통 지침(한자 표기)을 따른다. 솔로몬 저널 본문에는 한자를 되도록 쓰지 않는다.

## 6. 게시 순서 (「올려」 후)

1. 저장소 맨 위 폴더에서:
   ```bash
   git pull --rebase
   python3 tools/update_note.py
   ```
   "고칠 곳"이 나오면 고치고 다시 실행. "완료"가 나와야 다음으로. "참고"는 읽고 판단한다.
2. 확인: `note.html`을 열어 새 기사가 맨 위(날짜순)에 있고 분류 칩·검색이 되는지 본다. 가능하면 모바일 390px 너비로 캡처해 본다.
3. 올리기:
   ```bash
   git add data/note.json note.html index.html
   git commit -m "솔로몬 저널: (기사 제목 요약)"
   git pull --rebase && git push origin HEAD:main
   ```
   커밋 메시지 끝에는 그 채팅 안내에 있는 Co-Authored-By 줄을 붙인다.
4. 1~2분 뒤 https://juniorsolomon.com/note.html 이 바뀌었는지 확인한다(못 열면 보고에 적는다).

## 8. 화면 구성 (바꾸지 말 것)

- 솔로몬 저널 페이지: 머리말(소포스 입시 노트 바로가기 포함) → '최근 세 줄'(최신 3건) → 분류 칩·검색 → 기사 카드(분류·날짜·언론사 / 제목 / 풀이 / 세 줄 요약 / 솔로몬 노트 / 원문 기사 보기) → 소포스 입시 노트 안내
- 홈페이지 첫 화면 '솔로몬 저널' 칸: 최신 3건이 자동으로 바뀐다.
- 디자인·분류·페이지 구조를 바꾸려면 원장님 승인을 먼저 받는다. 분류를 바꿀 때는 `tools/note.py`의 `CATS`와 `tools/update_note.py`의 `CATS`를 함께 고친다.
