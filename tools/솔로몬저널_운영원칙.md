# 솔로몬 저널 운영 원칙 (원장님 결정 모음)

솔로몬 저널은 「솔로몬 저널」 채팅이 전담한다. 작업 전 반드시 `git pull`.

## 1. 핵심 원칙 — 지적 큐레이션과 단순화 (2026-11-27)
- 버튼은 직관적으로, 필요한 자리에 작게. 누르면 창이 하나 더 뜨는 단계는 모든 홈페이지에서 뺀다.
- 기사 공유: 기사 아래 작은 아이콘 한 줄(카카오톡·네이버 블로그·X·스레드·링크 복사), 누르면 바로 동작.

## 2. 기사 올리기
- 원장님이 링크·캡처를 주면 원문을 직접 읽어 확인 → 시안을 채팅에 → 「올려」 뒤에만 main 게시.
- 원문이 열리지 않으면 본문 캡처를 요청한다. 검색 요약만으로 숫자·날짜를 쓰지 않는다.
- 같은 주제의 이어지는 보도는 새 기사 대신 기존 기사의 '후속보도'로 붙인다.
- 실행: `python3 tools/update_journal.py` (journal.html · 첫 화면 최신 3건 · 메뉴 NEW 자동 갱신)
- 알림톡: 하루 1회 아침 묶음 발송. 발송이 켜진 뒤에는 main 게시 = 다음 날 아침 발송이므로 「올려」 전 게시 금지.

## 3. 시사 학습지 협업 (2026-11-29)
- 토론하기 좋은 기사는 학습지 초안을 「Op / 자기주도 일일 학습지 PDF」 채팅으로 보낸다. 교재번호·PDF는 그 채팅이 맡는다.
- 그 채팅은 이쪽으로 메시지를 보낼 수 없으므로, 작업 전 그 채팅 기록을 확인해 이어받는다.
- **중요한 주제는 전학년 세트로 만든다**: 초1-2 · 초3-4 · 초5-6 · 중등. 학년마다 문제 수준과 분량을 맞춘다.

| 학년 | 시간 | 읽기 | 사실·생각 | 질문 만들기 | 쓰기 |
|---|---|---|---|---|---|
| 초1-2 | 20분 | 5문장 | ○✕ 3문항 | 1개(교사와 함께) | 1문장 |
| 초3-4 | 30분 | 7문장 | 4문항 | 2개 | 3문장 |
| 초5-6 | 40분 | 9문장 + 숫자 | 5문항 | 3개(필수) | 200자 |
| 중등 | 45분 | 자료표 전체 | 사실·의견 분류 + 자료 비판 | 3개(필수) | 400자 논술 |

## 4. 두 사이트 공용
- 저널 홍보 페이지(journals.html)는 juniorsolomon-site에서 고치고 `bash tools/publish_journals.sh`로 소포스에 함께 올린다.
